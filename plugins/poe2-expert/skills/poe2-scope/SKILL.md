# Path of Exile 2: no knowledge here yet

This pack has **no Path of Exile 2 knowledge**. The PoE2 plugin will be built after PoE2 1.0 launches (2026-12-11).

1. **Establish the game first.** If the user has not said PoE1 or PoE2, ask before answering any mechanics, item, skill or economy question. Many names exist in both games (skills, keywords, currency, uniques) with different rules.
2. **For PoE2 questions:** say plainly that this pack has no PoE2 knowledge, then answer only from current sources you can check (patch notes, the official site, poe2db, the community wiki), cite them, and mark anything else as unverified.
3. **Never carry PoE1 knowledge into a PoE2 answer** (or the reverse). Do not use the `poe1-*` skills or the knowledge MCP's `poe1` data for PoE2.
4. Snapshot and economy data in this pack are PoE1 only.
