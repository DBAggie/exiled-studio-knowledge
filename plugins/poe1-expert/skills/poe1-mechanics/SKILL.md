# PoE1 mechanics (patch 3.30)

## Before answering
1. **Confirm the game is PoE1.** If the user might mean PoE2, ask. Names shared by both games carry different rules. Never answer a PoE2 question from these references (`poe2-scope` skill).
2. **Game data is never recalled from memory.** Gem numbers, mod values, unique stats, base stats and passive stats come from the knowledge MCP (`get_gem`, `get_unique`, `get_base`, `get_passive`, `search_mods`, `resolve_stat`). If the MCP is not available, say the values are from memory and may be out of date.
3. **Read the reference file for the topic** below before answering a non-trivial question. Each file states its `patch`, `as_of`, sources and `verification`. If a note says a rule changed in a patch, use the 3.30 rule and say it changed.
4. **Say how sure you are.** A reference marked `unverified` is a draft: say so when the answer depends on it.
