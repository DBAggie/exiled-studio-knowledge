1. Confirm the game is PoE1 (`poe2-scope` skill for PoE2). Jargon overlaps between the games.
2. These files change with each league. Check the file's `league` and `as_of`; if it is an older league than the user's, say so.
3. League-specific strategy, meta and popularity are snapshot content: use `poe1-economy` and state its `as_of` and league.
4. All text here is our own. Ideas from guides, Reddit or the wiki are credited by link in each file's `sources`.
